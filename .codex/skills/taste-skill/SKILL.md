# Taste Skill: Anti-Slop Frontend Engineering

## Overview
Frontend engineering standards to eliminate generic, template-like AI output ("slop") and instill distinctive aesthetic taste, high typographic quality, and intentional motion.

## Core Directives
1. **Anti-Generic Layouts**:
   - Avoid standard bootstrap-like generic cards. Use bespoke grid systems, asymmetrical balance, and dynamic spacing scales.
2. **Tunable Visual Parameters**:
   - `DESIGN_VARIANCE`: Intentionally craft unique visual signatures for the specific domain (e.g. HFT Trading Swarm).
   - `MOTION_INTENSITY`: Subtle, purposeful transitions (150ms-250ms), smooth SVG paths, zero jarring animations.
   - `VISUAL_DENSITY`: Tailor density to the user persona (high-density compact dashboards for quantitative traders).
3. **Color & Contrast Harmony**:
   - Use curated HSL color tokens with mathematically balanced contrast ratios (WCAG AAA compliance).
