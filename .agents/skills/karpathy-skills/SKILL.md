# Andrej Karpathy Coding Principles

## Overview
Practical guidelines derived from Andrej Karpathy's core insights on maximizing the efficacy and reliability of AI coding agents while preventing runaway complexity.

## The 4 Golden Rules
1. **Think Before Coding**:
   - Never rush to write code. Explicitly state assumptions, identify hidden edge cases, and inspect the surrounding architecture first.
   - If requirements are ambiguous, clarify them rather than guessing.

2. **Simplicity First**:
   - Eliminate unnecessary abstractions, premature design patterns, and excessive layers of indirection.
   - The best code is clear, readable, and does exactly what is requested—nothing more.

3. **Surgical Modifications**:
   - Make precise, localized changes. Do NOT touch unrelated files or refactor working code unless explicitly requested.
   - Preserve comments, formatting, and existing conventions.

4. **Goal-Driven Verifiable Execution**:
   - Define concrete, measurable success criteria before executing.
   - Verify every change with automated tests or empirical script execution.
