# Skills for Real Engineers (Matt Pocock Methodology)

## Overview
A collection of 21 opinionated, high-discipline workflows designed for professional software engineers to ensure software quality, safety, and rapid maintainable iteration.

## Key Disciplines
1. **Product Requirements Documents (PRD)**:
   - Define exact user stories, acceptance criteria, and failure modes prior to coding.
2. **Strict Test-Driven Development (TDD)**:
   - Red -> Green -> Refactor cycle. Tests must assert behaviors, not implementation details.
3. **Architecture Review**:
   - Evaluate performance trade-offs, async vs sync bottlenecks, memory consumption, and dependency overhead.
4. **Git Safety & Clean Commits**:
   - Atomic commits, concise commit messages, zero accidental commits of credentials or secrets.
5. **Zero-Fluff Craftsmanship**:
   - Write idiomatic, modern code (modern Python 3.10+, modern TypeScript, modern CSS).
   - Reject outdated boilerplate and maintain high type safety.
