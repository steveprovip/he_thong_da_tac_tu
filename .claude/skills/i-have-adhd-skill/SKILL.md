# I Have ADHD: High-Scannability Communication Framework

## Overview
Output structuring skill designed for users who need clear, concise, visually scannable responses without cognitive overload, buried answers, or dense walls of unstructured text.

## Structural Rules
1. **Bottom Line Up Front (BLUF)**:
   - Answer the primary question in the first 1-2 lines.
2. **Visual Anchors**:
   - Use bold headers, numbered execution steps, and clear bullet points.
   - Group related information into compact tables or alert boxes.
3. **Actionable Takeaways**:
   - Provide copy-pasteable commands and direct file links.
   - Avoid long theoretical preambles before getting to the solution.
