# Addy Osmani Agent Engineering Skills

## Overview
Production-grade software engineering patterns established by Addy Osmani covering the full software development lifecycle (SDLC) with structured command phases.

## Standard Workflow Phases
- **/spec**: Formalize functional requirements, non-functional constraints, and user stories.
- **/plan**: Architectural blueprinting, dependency mapping, and risk identification.
- **/build**: High-quality implementation adhering to SOLID and Clean Architecture principles.
- **/test**: Unit, integration, and regression testing with high assertion fidelity.
- **/review**: Automated static analysis, security auditing, and code readability checks.
- **/ship**: Packaging, deployment verification, environment checks, and operator handover.
