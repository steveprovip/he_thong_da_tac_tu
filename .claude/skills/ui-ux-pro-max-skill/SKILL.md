# UI/UX Pro Max: AI Design Intelligence Framework

## Overview
Comprehensive UI/UX design intelligence framework enabling AI agents to craft award-winning, visually stunning, and responsive interfaces without generic template aesthetics.

## Design Systems & Style Museum
1. **Cyberpunk & HFT Terminal Style**:
   - Dark mode base (`#0b0e14`, `#10141e`), vibrant neon accents (Cyan `#00f2fe`, Emerald `#00ffa3`, Amber `#ffb703`, Crimson `#ff4b4b`).
   - Monospace typography for numbers and tickers (`JetBrains Mono`, `Fira Code`, `Outfit`).
2. **Glassmorphism**:
   - Multi-layered translucent panels (`backdrop-filter: blur(16px)`), subtle borders (`rgba(255,255,255,0.08)`), glowing radial gradients.
3. **Micro-Animations & Visual Feedback**:
   - Smooth CSS transitions (`cubic-bezier(0.4, 0, 0.2, 1)`), SVG pulses, dynamic glow effects on state changes.
4. **Information Density & Hierarchy**:
   - High visual scannability: distinct card components, real-time metric counters, status indicators, clean tabular telemetry.
